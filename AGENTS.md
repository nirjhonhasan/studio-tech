## What this is

Studio rental/booking app (Next.js 16 App Router, all code under `src/`). Routes `/studios`, `/studios/[id]`, `/my-listings`, `/my-bookings`, `/add-studio`, and the `(auth)` group are placeholder stubs — most `page.tsx` files are still empty. `README.md` is unmodified create-next-app boilerplate; ignore it.

## Commands

- npm only (lockfile committed). There is no test script or test framework.
- `npm run dev` / `npm run build` / `npm run start`.
- `npm run lint` runs plain `eslint`. It currently exits 1 on pre-existing shadcn scaffold files (`src/components/ui/carousel.tsx`, `src/hooks/use-mobile.ts`) failing the React Compiler rule `react-hooks/set-state-in-effect`. Treat those as pre-existing; check your own files with `npx eslint <path>`.
- Typecheck with `npx tsc --noEmit` (no typecheck script). Route types in `.next/types/` and `.next/dev/types/` are generated by `next dev`/`next build`, so run one first for full route-export validation.

## Gotchas

- **Never leave a route file empty.** Empty `page.tsx` files make `tsc --noEmit` fail with confusing `File ... is not a module` errors pointing at `.next/dev/types/validator.ts`. A stub route must at least `export default function Page() { return null }`.
- Route/layout props use this version's generated generic types (e.g. `LayoutProps<"/">` in `src/app/layout.tsx`), not hand-written `{ children: React.ReactNode }` shapes. Match the existing pattern.
- `next.config.ts` enables flags that change defaults from older Next.js: `cacheComponents` + `partialPrefetching` (data fetching is dynamic by default; opt into caching with the `use cache` directive) and `reactCompiler` (memoization is automatic — don't add `useMemo`/`memo`, and `react-hooks` lint is strict about setState-in-effect). Docs for all of these are bundled under `node_modules/next/dist/docs/`.
- Tailwind v4 with no `tailwind.config.*`: theme tokens live in `src/app/globals.css`; CSS is processed via the `@tailwindcss/turbopack` rule in `next.config.ts`.
- UI components are shadcn **"base-nova" style built on Base UI (`@base-ui/react/*`), not Radix**. Add components with the shadcn CLI (configured via `components.json`) instead of hand-porting Radix snippets. Icons come from `lucide-react`; `cn()` is re-exported from the `cn` package in `src/lib/utils.ts`.
- Path alias `@/*` → `src/*`.
